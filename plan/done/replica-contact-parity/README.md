## 1. Контекст

### Как устроено предсказание

- Хост симулирует матч на Rapier (`rapier2d` 0.34, `enhanced-determinism`). Тело танка получает
  `soft_ccd_prediction(min(width, height))` — `map.rs` ≈1653, у танков то же делает игра. Поэтому контакт строится,
  пока тела ещё разведены: это спекулятивный контакт.
- Клиент игры (`vimp-tanks/core/src/client/predictor.rs`, `Predictor::resolve_world`) предсказывает свой танк
  репликой: собственным мини-решателем из примитивов движка:
  - `client/collision.rs`: `obb_manifold`, `collect_block_contacts_into` (он внутри зовёт `obb_manifold`),
    `obb_vs_obb_within`;
  - `client/rigid_body.rs`: `separate_bodies`, `apply_contact_impulse`, `ContactImpulses`, `integrate`,
    `combine_surfaces`, `MAP_SURFACE`.
- Порядок шага в игре:
  1. собрать контакты на позе начала шага с зазором `prediction`;
  2. один раз `separate_bodies` на пару;
  3. `SOLVER_ITERATIONS = 4` проходов `apply_contact_impulse` по всем точкам;
  4. интегрировать позицию скоростью;
  5. демпфировать скорость. Формула в игре — `Predictor::integrate`, в движке — `rigid_body::integrate`:
     позиция += v·dt, затем v *= 1/(1 + dt·damping).
- Документация этих «четырёх деталей»: `docs/en/core.md` ≈ строки 386–450 и `docs/ru/core.md` ≈405 («Четыре
  детали…»).

Игрок видит рывок танка при каждом лобовом ударе в стену.

### Замер (параллельный прогон хоста и реплики, шаг 1/120 с)

Танк `m1`: плотность 200, `restitution` 0.1, `friction` 0.5. Стена — `MAP_SURFACE`: `restitution` 0, поэтому по
правилу среднего e = 0.05, трение 0.35. Танк едет прямо в грань стены на скорости ≈140–145 ед/с.

| случай | хост `vy`, `vx`, `ω` на шаге удара | реплика `vy`, `vx`, `ω` |
| --- | --- | --- |
| страж торца рампы, танк 12×9 | −7.24, 0, 0 | 27.25, 2.54, 0.226 |
| тот же страж, танк 8×6 | 34.11, 0, 0 | 120.79, 0.96, 0.107 |
| длинная стена, лобовой удар, танк 8×6 | −6.28, 0, 0 | 43.31, −1.57, −0.219 |

На длинной стене до удара хост и реплика совпадают бит в бит. На шаге удара:
- хост встаёт вплотную к грани (проникновение ≈0.014) и уходит назад со скоростью `−e·v` (0.05·144.6 = 7.23);
- реплика встаёт у грани, но сохраняет скорость ≈ `зазор/dt` минус отскок от остатка, и корпус получает ложное
  вращение и боковой снос.
