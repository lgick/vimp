# Направление G: 4 бага рендера и звука (vimp + vimp-tanks)

Четыре дефекта игрового клиента. Баги 1, 2 и 4 — три следствия одной
архитектурной черты: сущность на полотне живёт не по данным хоста, а по
локальным решениям (предикт, конструктор part'а), при этом механизмы сброса
(`CLEAR` → `clientCore.reset()` → `soundManager.reset()`) не согласованы
между собой. Баг 3 независим: у приложения нет обработки потери
WebGL-контекста, при том что 100% видимых пикселей — GPU-only
`RenderTexture` без CPU-источника.

Затрагивает оба репозитория: `/Users/dmitry/Sites/my/vimp` (движок) и
`/Users/dmitry/Sites/my/vimp-tanks` (плагин игры).

## Влияние на релиз (флагуется заранее)

- **Крейт `vimp-engine-core`**: меняются `client/game.rs` (`reset` обнуляет
  `my_game_id`, новый `resync`) и `abi.rs` (новый метод в
  `export_client_core_abi!`) → bump **minor**. `vimp-tanks/core/Cargo.toml`
  обязан подтянуть версию и пересобрать WASM.
- **npm `vimp-engine`**: в `files` входит `src/host` (правится
  `RoundManager.js`) → bump **patch**. `src/client/**` в `files` нет.
- **`ENGINE_API_VERSION` не меняется**; новый метод ABI требует пересборки
  и переиздания `@vimp-games/tanks`. Совместимость — вызов
  `clientCore?.resync?.()`.
- Версии не правятся и не публикуются — это делает разработчик
  (`docs/en/publishing.md`).

## Ручной e2e

1. Локальный контур: `npm run dev` + `npm run dev:auth`, плагин слинкован в
   обе стороны; хост в одном окне, гость — во втором.
2. **Баг 1/2**: смена карты → полотно пустое, звука двигателя нет; вступить
   в команду → танк появляется со звуком, при движении меняется тон.
3. **Баг 4**: поставить бомбу → один сэмпл `bombHasBeenPlanted` без обрыва,
   спрайт не «моргает»; чужая бомба слышна ровно один раз.
4. **Баг 3**: снять диагностику, затем после лечения переключить вкладку на
   2–5 минут и вернуться: сцена рисуется, консоль чистая.
5. Регресс: раунд-рестарт после фрага, смерть и респаун, выстрелы и взрывы.
