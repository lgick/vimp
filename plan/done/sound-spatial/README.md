# План: пространственный звук — виртуальная высота и профили проекции

Индекс этапов. Исходная постановка задачи и разбор отвергнутых вариантов —
[`original-statement.md`](original-statement.md).

**Эта страница — обязательное чтение перед любым этапом.** В ней единицы
измерения, эталонная математика и схема конфигурации; файлы этапов на них
ссылаются и не повторяют. Дальше открывается ровно один файл нужного этапа.

## Контекст

`packages/engine/src/client/SoundManager.js` позиционирует мировой источник
в плоскости слушателя: `sound.pos(dx, 0, dy, id)` при слушателе в
`(0, 0, 0)` (строка 484). Источник в 20 единицах справа от игрока оказывается
**строго в правом ухе на микроскопическом расстоянии**: HRTF-свёртка глушит
левый канал и даёт гребенчатую окраску.

Вторая половина проблемы — дискретность. Порог `MIN_SPATIAL_DISTANCE = 16`
(строка 10) переключает источник между двумя разными состояниями: внутри
порога `PannerNode` не создаётся вовсе (сухое стерео идёт прямо в gain), за
порогом Howler создаёт узел лениво (внутри `setupPanner` — пара
`pause()/play()`, то есть щелчок) и звук мгновенно прыгает в крайнее ухо со
сменой тембра. На слух — резкая разница «бомба под танком» / «бомба рядом».

**Решение:** виртуальная высота слушателя (Virtual Elevation) + плавное
рассеивание в ближней зоне (Spread), как в Wwise/FMOD для 2D-игр. Слушатель
поднят над плоскостью игры на `virtualElevation`, внутри `innerRadius`
вектор на источник плавно гасится через `smoothstep`. Позиция считается
одной непрерывной формулой на каждом кадре. Геометрия проекции выбирается
профилем: `topDown` / `sideScroller` / `cockpit`.

## Инварианты плана

1. **Ничто новое не обязательно.** Блок `parts.sounds.spatial`
   необязателен: игра, которая его не объявляет, получает движковые дефолты
   и звучит правильно. `ENGINE_API_VERSION` не бампается,
   `contract/surface.json` не редактируется, из замороженной поверхности
   ничего не удаляется.
2. **`spatial: false` не трогаем.** Свой двигатель и свой выстрел остаются
   полностью непространственными и **никогда** не получают `PannerNode` —
   поведение сохраняется дословно, вместе с двумя покрывающими его тестами.
3. **Rust-ядро не затрагивается.** `npm run core:test` в этой задаче не
   нужен.
4. **Приоритеты и лимит голосов не трогаем.** `WORLD_VOICE_LIMIT = 30`,
   формула `priority² / max(distance², 1)`, отсев одноразовых звуков —
   как есть.
5. **Коммиты не создаём.** Все правки остаются в рабочем дереве; `version`
   не правим, `npm run release` не запускаем.

## Единицы измерения — прочитать до того, как трогать числа

**Мировая единица ≠ экранный пиксель.** Без этого факта дефолты подобрать
невозможно.

В `SoundManager` приходят **мировые** координаты (`camera[0]`, `camera[1]`
из горячего буфера ядра; `regSound.position` от частей игры). Экранный
масштаб считает
`packages/engine/src/client/components/model/CanvasManager.js`:

```
currentScale = baseScale * (ширина окна / _designWidth)      // строка 147
_designWidth = 1920                                          // строка 38
finalScale   = currentScale * _camZoomModifier               // строка 297
```

Замеренные значения двух существующих игр (окно 1920×1080, зум 1):

| | `vimp-tanks` | `vimp-snakes` |
| --- | --- | --- |
| `gameConfig.mapScale` | `0.3` (`src/config/game.js:36`) | `1` (`src/config/game.js:80`) |
| `baseScale` игрового полотна | `'5:1'` → `5` (`src/config/client.js:216`) | `'1:1'` → `1` (`src/config/client.js:89`) |
| 1 мировая единица = | 5 экранных px | 1 экранный px |
| тайл карты | `step 32 × 0.3 = 9.6` мировых ед. | `STEP 128` мировых ед. |
| габарит игрока | корпус `8 × 6` ед. (`core/src/motion.rs:15`: `size*4 × size*3` при `size: 2`), полудиагональ `5` | `baseRadius: 14` (`src/data/models.js:44`) |
| половина экрана по горизонтали | `960 / 5 = 192` ед. | `960` ед. |
| половина экрана по вертикали | `540 / 5 = 108` ед. | `540` ед. |

Отсюда два правила:

- **`innerRadius` — габарит игрока в мировых единицах**, а не «40 px для
  Full HD»: у танков `≈ 5`, у змейки `≈ 14`. Значение `40` верно только для
  игры, где мировая единица равна экранному пикселю.
- **`virtualElevation` калибруется от видимой полувысоты экрана**:
  `H ≈ (высота полотна / 2) / currentScale`. Ориентир: `H`, равная
  полувысоте, даёт на краю экрана угол `atan(полуширина / H) ≈ 60°`
  (выраженная локализация), а на дистанции габарита игрока — единицы
  градусов (мягкий сдвиг).

Движковый дефолт `180`/`40` рассчитан на масштаб 1:1 и остаётся таким;
tanks объявляет свои значения (этап 7), snakes — только `innerRadius`
(этап 8).

## Эталонная математика

Слушатель всегда в `(0, 0, 0)`, источник задаётся вектором относительно
него. Мировые оси: `x` — вправо, `y` — **вниз** по экрану.

```
dx  = x - listenerX
dy  = y - listenerY
d2d = Math.hypot(dx, dy)

zoom = множитель зума камеры (1 = покой, < 1 = отдаление)
H    = virtualElevation / zoom
R    = innerRadius      / zoom

spread = smoothstep(0, R, d2d)     // 0 в центре, 1 за радиусом
sx = dx * spread
sy = dy * spread
```

Профиль отображает `(sx, sy, H)` в оси Web Audio `(X, Y, Z)`:

| Профиль | `X` | `Y` | `Z` | дефолтный `panningModel` |
| --- | --- | --- | --- | --- |
| `topDown` | `sx` | `-H` | `sy` | `HRTF` |
| `sideScroller` | `sx` | `-sy * verticalFactor` | `-H` | `equalpower` |
| `cockpit` | `sx` | `-sy` | `-H` | `HRTF` |

Почему так:

- **`-H` по Y в `topDown`**: слушатель над плоскостью, источник под ним.
  При `d2d = 0` позиция ровно `(0, -H, 0)` — строго снизу по центру,
  одинаково в оба уха, без ушной фильтрации. При `dx = 20, H = 180` угол
  `atan(20/180) ≈ 6.3°`; при `dx = 600` — `≈ 73°`.
- **`-sy` в `sideScroller`/`cockpit`**: мировой `y` растёт вниз, а ось Y Web
  Audio (вектор «вверх» слушателя из `Howler.orientation(0,0,-1,0,1,0)`) —
  вверх. Без знака звук прыжка ушёл бы вниз.
- **`verticalFactor` (дефолт `0.2`)** занижает вертикаль платформера: в
  Mario высота на слух почти не читается, а полная вертикаль в HRTF даёт
  окраску без пользы.
- **`equalpower` для `sideScroller`**: в виде сбоку «спереди/сзади»
  физически бессмысленно, а чистый тембр лево/право важен.
- **`smoothstep` вместо порога**: непрерывна вместе с первой производной —
  ни щелчка, ни ступеньки.
- **Затухание не ломается на нуле**: реальная 3D-дистанция никогда не
  меньше `H`, поэтому `refDistance = 200 > H = 180` даёт полную громкость
  вблизи игрока.

### Что НЕ масштабируется зумом

Зум делит только `virtualElevation` и `innerRadius`. `maxDistance` — и
отсечка в `_updateSpatialSound`, и отсев кандидатов в `processAudibility` —
остаётся в мировых координатах.

Причина: `refDistance`/`maxDistance`/`rolloffFactor` — атрибуты самого
`PannerNode`, они ставятся один раз через `pannerAttr` на уровне `Howl` и
покадрово не пересчитываются. Масштабирование только JS-отсечки создало бы
окно, где движок считает источник слышимым, а узел уже отдал тишину, — это
не видно ни в одном тесте и слышно как случайно пропадающие звуки.

## Схема конфигурации

Все ключи необязательны; отсутствующие берутся из движковых дефолтов.
Слияние выполняет `deepMerge` в
`packages/engine/src/lib/buildClientConfig.js:11` (рекурсивно сливает
объекты, заменяет массивы и скаляры).

```javascript
parts: {
  sounds: {
    codecList: ['webm', 'mp3'],
    spatial: {
      mode: 'topDown',          // 'topDown' | 'sideScroller' | 'cockpit'
      virtualElevation: 180,    // мировых ед., высота ушей над плоскостью
      innerRadius: 40,          // мировых ед., габарит игрока
      verticalFactor: 0.2,      // только sideScroller: вклад вертикали
      panningModel: 'HRTF',     // 'HRTF' | 'equalpower'
      distanceModel: 'inverse', // 'linear' | 'inverse' | 'exponential'
      refDistance: 200,         // мировых ед., до неё громкость 100 %
      maxDistance: 1200,        // мировых ед., дальше — тишина
      rolloffFactor: 0.9,
    },
    sounds: { /* каталог */ },
  },
}
```

Изменение движковых дефолтов относительно текущих `PANNER_SETTINGS`
(`SoundManager.js:13-22`): `refDistance 150 → 200`, `maxDistance
1000 → 1200`, `rolloffFactor 1 → 0.9`. Это компенсация виртуальной высоты:
минимальная 3D-дистанция теперь не `0`, а `H`, и без сдвига `refDistance`
все мировые звуки стали бы тише прежнего.
