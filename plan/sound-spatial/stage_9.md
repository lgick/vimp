## 9.1. Журнал движка

`packages/engine/CHANGELOG.md`, секция `## [Unreleased]` (строка 10).
Подзаголовок задаёт уровень релиза — список закрыт, `npm run release`
останавливается на любом другом.

```markdown
## [Unreleased]

### Added

- Клиентский конфиг игры может объявить геометрию пространственного звука
  (`parts.sounds.spatial`): профиль проекции `topDown` / `sideScroller` /
  `cockpit`, виртуальная высота слушателя, радиус рассеивания в ближней
  зоне и атрибуты `PannerNode`. Блок необязателен — игра без него получает
  движковые дефолты. `setListenerPosition` принимает третьим аргументом
  множитель зума камеры. Статическую проверку блока делает новое правило
  контракта `E6`.

### Fixed

- Мировой звук вблизи слушателя больше не переключается скачком: дед-зона
  `MIN_SPATIAL_DISTANCE` убрана, позиция считается одной непрерывной
  формулой, а источник под игроком звучит из-под него, а не в одном ухе.
```

Текст — английский (журнал ведётся по Keep a Changelog на английском);
приведённый выше блок нужно перевести, сохранив смысл и разбиение по
подзаголовкам.

`packages/engine/core/CHANGELOG.md` и
`packages/create-vimp-game/CHANGELOG.md` **не трогаются**.

Журналы игр правятся на своих этапах ([7](stage_7.md), [8](stage_8.md)).

## 9.2. Что доложить при сдаче работы

Правило «Release impact» из `CLAUDE.md` требует сообщить это без
напоминания:

- **артефакт** — npm-пакет `vimp-engine` (`packages/engine/src/**` входит в
  `files`);
- **бамп** — **minor** (`0.32.3 → 0.33.0`), потому что в `[Unreleased]` есть
  `### Added`;
- **игровому репозиторию следовать не обязано**: старый конфиг валиден,
  крейт не менялся;
- **`⚠️ Breaking` не применяется**: движок не начинает отвергать вход,
  который принимал раньше; `contract/surface.json` не менялся, из него
  ничего не удалено;
- **предпубликационные проверки** — какие из команд ниже реально прогнаны и
  с каким результатом.

`version` не править, `npm run release` не запускать, коммиты не создавать —
это делает разработчик.

## 9.4. Ручной smoke в браузере

`npm run dev` в движке при слинкованном плагине, **наушники обязательны**.
Это единственный способ проверить то, ради чего задача делалась.

1. Бросить бомбу под танк и медленно отъехать вбок: звук уходит в сторону
   плавно, без ступеньки в районе прежних 16 единиц и без смены тембра.
2. Постоять ровно на источнике: звук по центру, оба уха одинаково, без
   гудящей гребёнки.
3. Взрыв на краю экрана: локализация чёткая, сторона верная.
4. Разогнаться на максимум (динамический зум): панорама не дёргается при
   изменении зума, звук не становится внезапно шире.
5. Свой двигатель и свой выстрел: полное стерео сэмпла, без панорамы и без
   щелчков — регрессия на `spatial: false`.
6. Повторить пункты 1–3 в Safari: другой кодек (`mp3` вместо `webm`) и
   другая реализация HRTF.
7. `vimp-snakes`: подбор кристалла под головой и смерть рядом.

По итогам пунктов 1–4 фиксируется финальная `virtualElevation` танков
([этап 7](stage_7.md)), по пункту 7 — решение по змейкам
([этап 8](stage_8.md)).
