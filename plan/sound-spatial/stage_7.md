## Почему танкам нужны свои числа

У танков `mapScale: 0.3` (`src/config/game.js:36`) и `baseScale: '5:1'`
(`src/config/client.js:216`), то есть **мировая единица впятеро меньше
экранного пикселя**. Движковые дефолты (`180`/`40`, рассчитанные на масштаб
1:1) дали бы здесь стереобазу шириной в пять экранов, а `innerRadius: 40` —
радиус «габарита игрока» размером в пять корпусов.

Расчёт для окна 1920×1080:

- `currentScale = 5` → половина экрана: `192 × 108` мировых единиц;
- корпус `m1`: `8 × 6` мировых единиц (`core/src/motion.rs:15` —
  `size*4 × size*3` при `size: 2` в `src/data/models.js`), полудиагональ
  `hypot(8, 6) / 2 = 5`.

## 7.1. `src/config/sounds.js`

Текущий экспорт — строки 50–54 (`codecList`, `path`, `sounds`). Заменить на:

```javascript
export default {
  codecList: ['webm', 'mp3'],
  path: '/sounds/',

  // Геометрия пространственного звука. Числа в МИРОВЫХ единицах: у танков
  // mapScale 0.3 и baseScale 5, то есть мировая единица впятеро меньше
  // экранного пикселя, и движковые дефолты (180/40, рассчитанные на 1:1)
  // здесь дали бы стереобазу в пять раз шире экрана.
  spatial: {
    mode: 'topDown',

    // половина видимой высоты экрана: 1080 / 2 / 5 = 108 мировых единиц.
    // На краю экрана (192 ед. вбок) это угол ~60°, у корпуса — единицы
    // градусов
    virtualElevation: 108,

    // полудиагональ корпуса m1: 8 x 6 мировых единиц (motion.rs: size*4 x
    // size*3 при size: 2) -> hypot(8, 6) / 2 = 5. Взрыв внутри габарита
    // распределяется поровну в оба уха
    innerRadius: 5,
  },

  sounds,
};
```

**`innerRadius: 5`** — вычисляемая величина, менять её без изменения
`src/data/models.js` нельзя.

**`virtualElevation: 108`** — расчётная отправная точка. Подобрать на слух в
`npm run dev` в диапазоне 90–150 (критерий — пункты 1–4 ручного смоука
[этапа 9](stage_9.md)) и зафиксировать финальное число вместе с причиной в
комментарии.

`refDistance` / `maxDistance` / `rolloffFactor` **не объявлять**: движковые
`200`/`1200`/`0.9` в мировых единицах танков — это примерно один и шесть
полуэкранов, что соответствует прежним `150`/`1000` и на слух проверено.
