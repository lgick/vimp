# vimp-engine

VIMP — движок-приложение: мастер (лобби, WebRTC-сигналинг), P2P-транспорт,
Worker-хост, мета-модули матча, MVC-каркас клиента. Игровые правила
(например, `@vimp/tanks`) подключаются динамически через
[plugin-api](https://github.com/lgick/vimp/blob/main/docs/en/plugin-api.md)
— этот пакет их не содержит.

Документация: https://github.com/lgick/vimp/tree/main/docs/en
