# vimp-engine-core

VIMP — движковый каркас симуляции: физика (`rapier2d`), карта, кодек
снапшот-фрейминга, интерполяция/предикт/raycast-примитивы, нав-утилиты. Без
wasm-bindgen — WASM-ABI обёртки собирает крейт конкретной игры (например,
`@vimp/tanks`'s `GameCore`/`ClientCore`).

Документация: https://github.com/lgick/vimp/blob/main/docs/en/core.md
